# Distribution

Release authorized: Joe Walker, 2026-10-23. This is an unofficial, non-commercial, offline-only
fan mod. It is not affiliated with or endorsed by Saber Interactive, Focus Entertainment or
Games Workshop. If the rights holders object, the release is pulled.

The source snapshot and installer contain only the mod's own code and permitted dependencies.
The data needed by the mod is built locally from the player's own installed copy of the game.
No game data, copied game instructions, decompiles, disassembly or game-process dumps ship.
Third-party notices are in `installer/THIRD_PARTY_NOTICES.txt`; the mod's code is MIT.

The release repository receives cleaned source snapshots. Private development logs, agent
handoffs, internal plans and raw run evidence are excluded. Public technical pages describe
current behaviour and contributor procedures.

Version 1.0.0 starts the release sequence from the current source. The repository and its test
release are being prepared privately. Making them public is a separate decision.

The developer publishing script checks this authorisation and requires a public repository
before publishing through that script. See [Contributing](../CONTRIBUTING.md) for accepted changes.
